# Library Management System

A simple web-based Library Management System built using Flask, HTML5, and CSS3.

## Features

- Add new books
- Display all books
- Borrow books
- Return books
- Check book availability
- Flash messages for user feedback
- Input validation
- Responsive design

## Technologies Used

- Python
- Flask
- HTML5
- CSS3
- Jinja2

## How to Run

1. Create and activate a Python virtual environment.

2. Install Flask:

pip install Flask


3. Run the application:

python app.py

4. Open the application in a browser:

http://127.0.0.1:5000

Data Storage

Book data is stored in an in-memory Python list. Therefore, the data will reset when the Flask server is restarted.
